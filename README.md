# RESQ_Mobile-App-Testing 🚗🚨

## Overview

This repository contains QA documentation of Final Year Project, **RESQ: A GPS-Based Mobile Application for Locating Vehicle Assistance Services**, covering functional of key user flows such as authentication, booking, tracking and other functions.

Purpose: To validate functionality, usability, user experience, system behaviour through structured test scenarios and positive/negative test cases.
